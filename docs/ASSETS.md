# Assets: how to replace the art

All art is original and was generated by `scripts/generate-assets.mjs` as plain SVG files in `public/assets/`. Nothing loads from the internet.

## Replacing an image
1. Put your file in `public/assets/...` with the **same name**. For example, replace `towers/archer_1.svg`.
2. To use PNG, JPG or WebP, change the path in `src/game/config/assetManifest.ts`, for example `assets/towers/archer_1.png`.
3. Images are scaled to their in-game size automatically, so any resolution works. About 2× the display size looks crisp.

| Folder | Content | Canvas / facing |
|---|---|---|
| `towers/` | `{tower}_{1,2,3}.svg`: visual tier 1 (levels 1–2), tier 2 (3–4), tier 3 (5); plus `cannon_barrel.svg` | 128×160. The tower's foot sits near the bottom centre. The barrel points right and pivots near its left end. |
| `enemies/` | one file per enemy | 96×96, **facing right** (flipped automatically), feet at the bottom |
| `bosses/` | one file per boss | 160×160, facing right |
| `projectiles/` | arrow, cannonball, bomblet, orb, ice, bullet, firepot | pointing right |
| `world/` | ground tiles (seamless 128×128), castle, decorations | |
| `ui/` | coin, heart, swords, gate, flag, emblem (the emblem is also the favicon) | |

## Regenerating
- `npm run assets` writes only **missing** files, so your replacements are kept.
- `npm run assets:force` overwrites everything with the generated art.

## Sound
Sound effects are synthesised in `src/game/audio/SoundSystem.ts`, so there are no audio files. To use recordings, load them in `PreloadScene` and play them from `SoundSystem.play()`.
